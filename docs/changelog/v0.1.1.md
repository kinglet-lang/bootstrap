## v0.1.1

First release with native **Windows** support for the LLVM backend, plus a
one-command installer.

### Platforms

- **Windows native backend** — `kinglet` now builds with the LLVM backend on Windows (MSYS2 MinGW LLVM), and `kinglet run` / `kinglet build` execute programs natively. Previously Windows was compile-only and `run`/`build` were POSIX-only stubs.
- The Windows release archive is self-contained: `kinglet.exe` ships with its MinGW runtime and `libLLVM` DLLs, so it runs without MSYS2 on `PATH`.

### Distribution

- **`curl | sh` installer** — `scripts/install.sh` installs the latest stable (non-prerelease) release for macOS/Linux and wires it onto `PATH`. Prereleases (`-rc`, `-alpha`, `-beta`, `-dev`) are skipped automatically; set `KINGLET_VERSION=<tag>` to install a specific or prerelease version.

### Build

- New `clang_base_path` GN arg points the Windows toolchain at the MinGW `clang++` / `llvm-ar` matching the LLVM libraries; `scripts/setup.ps1` and `scripts/build.ps1` detect LLVM and build the native backend.
- `link_objects` honours `KINGLET_CXX` so the native backend AOT-links user programs with the matching `clang++` at runtime.

### Internal

- `release.yml` builds LLVM-native archives for Ubuntu, macOS, and Windows, and bundles the MinGW runtime DLLs into the Windows archive.
